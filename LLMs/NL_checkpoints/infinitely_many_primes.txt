statement:  There are infinitely many prime numbers.
proof:      Suppose there are only finitely many primes p_1, ..., p_n. Let N = p_1 p_2 ... p_n + 1. Since N > 1, N has a prime factor p. Then p is one of p_1, ..., p_n, so p divides p_1 p_2 ... p_n. Since p also divides N, p divides N - p_1 p_2 ... p_n = 1, which is impossible. Therefore there are infinitely many primes.
